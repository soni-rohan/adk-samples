* `PROJECT_ID` the project where your Apigee organization is located
* `APIGEE_HOST` the externally reachable hostname of the Apigee environment group that contains APIGEE_ENV
* `APIGEE_ENV` the Apigee environment where the demo resources should be created
* `APIGEE_APIHUB_PROJECT_ID` the project where your Apigee organization is located (same as project ID) 
* `APIGEE_APIHUB_REGION` the region where your API Hub is located
* `CLIENT_ID and CLIENT_SECRET` in the Google Cloud console, go to APIs & Services -> Credentials. Click +Create Credentials -> OAuth client ID -> Application Type = Web application and add a Name for your client. To find your redirect URI, run adk web in your cloud shell and copy the corresponding URL. Then, click +Add URI in the create OAuth client ID page and paste the URL. Click save.
* `REDIRECT_URI` same as above
